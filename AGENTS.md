# Emulsion

This is the canonical open-source monorepo. Native source is under apps/ios,
website and PWA source under apps/web. Keep Cloudflare's root `node build.mjs`
entry point and `dist` output stable. Rebuild and run `node test.mjs` before
committing; CI checks all of dist. Do not add credentials or private App Store
review records. Keep GLSL and Metal math, plate recipes and palettes aligned.
The current product is still wallpapers; motion belongs only in website previews.
Use real app captures for promotional previews. Respect reduced motion and pause
video in hidden tabs. Never add AI attribution to commits or PRs.
